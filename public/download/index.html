Installing

  1. Open the downloaded .dmg and drag ClaudeBox into Applications.
  2. The first launch shows “ClaudeBox can’t be opened because Apple cannot check it for malicious software.” That is expected — the app isn’t signed with a paid Apple Developer certificate.
  3. Open System Settings → Privacy & Security, scroll down, and press Open Anyway. Or run xattr -cr /Applications/ClaudeBox.app in Terminal once.
  4. Launch it from Applications like any other app.
Which one do I want? Macs from 2020 onwards (M1/M2/M3/M4) take the arm64 build; older Intel Macs take x64. The button above already picked for you. The .zip holds the same ClaudeBox.app as the .dmg — use it if you'd rather unzip than mount a disk image.
